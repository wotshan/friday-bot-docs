Privacy Policy for Friday Bot

1. Information We Collect
To function properly, Friday Bot collects and stores minimal necessary data, such as:
- Discord Server IDs and Channel IDs
- User IDs for command execution and song requests
- Guild language and configuration preferences

2. How We Use Data
Collected data is used solely to provide core bot functionalities (such as music playback, queue management, and language settings). We do not sell, trade, or transfer your data to third parties.

3. Data Security
We implement reasonable technical measures to secure stored configurations (like server prefixes and language settings).

4. Contact
For any questions regarding this Privacy Policy, you can reach out via your Discord support channel.
