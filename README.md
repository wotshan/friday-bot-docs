## <img src="https://raw.githubusercontent.com/Tarikul-Islam/animated-icons/master/icons/Aviation/Rocket.gif" width="30" align="center" /> Overview
Friday is a next-generation music bot built for Discord, featuring seamless multi-platform streaming, live lyrics, and an interactive 3-row button control interface with zero clutter.

---

## <img src="https://raw.githubusercontent.com/Tarikul-Islam/animated-icons/master/icons/Color/Gear.gif" width="30" align="center" /> Tech Stack & Platforms
* **Core Runtime:** Node.js (`discord.js` v14)
* **Audio Engine:** Lavalink Client
* **Streaming Integrations:** YouTube, Spotify, iTunes / Apple Music
